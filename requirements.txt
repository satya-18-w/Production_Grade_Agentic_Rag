# --- PPTX VECTOR-SHAPE DIAGRAM RENDERING (Track E, optional) ---
# Renders PPTX slides built from native shapes (no embedded picture to
# extract) to PNG via headless LibreOffice. pdf2image is a thin wrapper
# around the poppler-utils system binary (pdftoppm/pdftocairo) — NOT
# bundled by pip. Both LibreOffice and poppler must be installed
# separately on the host (e.g. `apt-get install libreoffice poppler-utils`
# on Debian/Ubuntu). This is the one loader in the codebase with a system
# binary dependency; if either is missing, rendering degrades to "no
# rendered slides" rather than failing ingestion — see
# app/ingestion/loaders/images.py::render_pptx_diagram_slides().
pdf2image                   # PDF page -> PIL Image, via poppler (system dependency, not pip-installed)
